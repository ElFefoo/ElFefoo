## 🚀 Proyectos destacados

### 📊 Enci-Intel — Inteligencia de mercado con IA
Plataforma web de inteligencia de mercado para el sector veterinario. Agentes automáticos recopilan información pública a diario y generan alertas; incluye un asistente con IA que responde consultas técnicas a partir de documentos (RAG).

**Mi aporte:** principal contribuidor del equipo — pipeline CI/CD con GitHub Actions, agentes programados en la nube y optimización de rendimiento.<br>
**Stack:** React + TypeScript · FastAPI · Firestore · Gemini · Google Cloud Run · GitHub Actions<br>
🔗 [Repositorio](https://github.com/M4UR1C1O0/Enci-intel-proyect)

### 📈 Predicción de siniestros de tránsito en Chile — Data Science
Análisis y modelamiento de datos reales de CONASET (1972–2024) para predecir fallecidos en siniestros de tránsito. Incluye limpieza de datos, regresión lineal múltiple, regresión logística, árbol de decisión y una red neuronal (perceptrón multicapa).

**Stack:** Python · Pandas · scikit-learn · TensorFlow/Keras · Matplotlib<br>
🔗 [Repositorio](https://github.com/M4UR1C1O0/Trabajo-N-1-Data-Science)
